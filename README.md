# Fastball Battle (previously known as 'ninja baseball')

An endless-type mobile game using the Flutter project.

## Aims

The aim of this game is to:
1- Gain further experience building apps
2- Learn how to make games
3- Analyse the formula used in popular games
4- Build a functioning app using the minimum amount of effort

## Challenges

I am not a graphic designer and cannot create any original graphics, thus I need to rely on publicly available images.

Additionally I do not want to spend alot of time building the game levels, thus I have opted for an endless type game where the progression can be automated

## Concept

At the moment the game i am building is a simple baseball batting game. It features a ninja with a baseball who is the main character, along with a baseball shooting machine

The aim of the game is to hit the ball every time it is blasted towards the ninja. If you hit it, then you gain a point. If you miss then u get 1 strike. 3 strikes and your out!

## Ideology behind building this app

Personally i believe the app store is an extremely crowded and competitive place where bad apps with good marketing/ASO can get a fair number of downloads before being noticed as badly designed and abonded. However very well built might never even see the light of day. So as part of that thought process I dont believe it is worth it to spend an excessive amount of time working on designing the perfect app and rather should just build 'just good' apps that all have the potential to attract users and only dedicate resources to the apps that actually provide an impact.
